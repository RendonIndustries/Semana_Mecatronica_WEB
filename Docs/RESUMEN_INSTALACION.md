## 🚀 Próximo Paso: Iniciar el Servidor

### Opción 1: Usar una nueva terminal (RECOMENDADO)

1. **Cierra esta terminal completamente**
2. **Abre una NUEVA terminal** (PowerShell o CMD)
3. Navega al proyecto:
   ```powershell
   cd D:\Repositorios_Git\Semana_Mecatronica_WEB
   ```
4. Inicia el servidor:
   ```powershell
   npm start
   ```
   O también:
   ```powershell
   node server.js
   ```

### Opción 2: Usar la ruta completa (temporal)

En la terminal actual, puedes usar:
```powershell
"C:\Program Files\nodejs\node.exe" server.js
```

Haz doble clic en: `iniciar_servidor.bat`
